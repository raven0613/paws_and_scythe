# Combo 牌型清單

`src/scenes/combo/combo.tscn` 已放入 gameplay 的 `(54, 101)`，位於關卡面板下方。每列使用共用的 `combo_row.tscn`，內容為「牌型 +分數」，文字與分數合成後置中。編輯器透過 `Preview Entries` 顯示「同花順 +200」、「葫蘆 +120」、「對子 +50」，資料集中於 `src/configs/combo/preview_*.tres`。執行 combo 或 gameplay 場景時，遊戲資料 `entries` 從空清單開始。遊戲每次操作後使用核心計分器採用的分組更新清單，名稱與分數依 `doc/spec.md` 的階級選取結果顯示，操作階段顯示原始分數，即卡牌點數總和加牌型達成分數。貓牌加成與得分資格的變化於結算時呈現，王牌貓排除的組在發動時降至零分並變暗，Hover 說明得分資格。每列保有張數與參與座標供盤面高亮使用。滑鼠進入時立即顯示牌型、張數、牌點與牌型達成分數拆解，以及逐張貓牌的加成明細；在同一列內移動時持續顯示，移出後收起。一般操作時，對應場上卡牌以整組牌型中心平滑放大，移開後恢復。牌型變動演出期間持續顯示說明，演出完成後依游標所在列恢復盤面 Hover。資訊窗使用 [共用即時 Hover](hover.md)。

## 外觀與多國語系

三張 `combo_frame_01`～`03` 為可上色素材，框色預設 `#6082B5`，牌型文字為 `#D8E5FA`，分數為 `#FFF0C2`，陰影為 `#151C28`。框與陰影各使用 NinePatchRect，四側保留 8 px，文字加長時加寬中間區域，文字縮短時恢復到對應框形的原始寬度。文字透過 Godot 的 `tr(hand_name)` 翻譯牌型名稱，語系改變時重新量測文字與更新尺寸。

選取 combo 根節點，可在 Inspector 設定 `Frame Color`、`Text Color`、`Score Color` 與 `Shadow Color`。之後背景換色時，主題流程可同時設定這些屬性，框色會更新，文字與陰影維持各自指定的顏色。

## 每列外觀

每條 combo 建立時取得自己的框形與水平偏移。分組延續、結算完成、插入、遞補及分數更新都保留該列的外觀；文字寬度依內容延展。新列的框形避開目前兩側相鄰列，水平偏移在設定範圍內選取並避開兩側偏移。刪除或合併後，保留列沿用原外觀，因此相鄰列可具有相同框形。多條新增時，先保留所有既有外觀，再由上至下配置新列。

`src/service/combo/combo_sequence.gd` 依牌型延續對應關係分配外觀，編輯器使用固定種子，執行時使用獨立的視覺亂數來源。外觀資料跟隨牌型列的生命週期保存。

## 動畫與完整清單

每次放牌落定、交換到位、挖牌退場或撤銷完成後，比較操作前後的牌型清單，依「退場、遞補、成立」依序演出。清單依核心提供的順序排列：原始分數由高到低，同分時橫向在前、直向在後，再依牌型第一格由上到下、由左到右。分數改變而名次變動的列以遞補演出移到新位置，新成立牌型依清單順序逐組播放，一組完整歸位且 combo 擾動停穩後，再開始下一組。成立演出的卡片路徑、同步點、操作範圍與可獨立替換的動畫分工詳見 [牌型成立與消失回饋](group_feedback.md)。

清單使用一對一牌型延續關係維持列節點。相同牌型與起始方向先配對完整相同路徑，其餘優先配對共同格數較多的組，同數時按原清單順序及新清單順序決定。順子延長、縮短及組內交換後維持同牌型的組沿用原列並更新內容；對子變三條等種類變更則退場後成立新列。兩組合併時保留一列，其餘退場；一組拆分時保留一列，額外的組播放成立演出。各組由各自的路徑與方向識別，交叉位置的牌可依序參與兩組演出。

新增列以自身中心從零放大，使用 Back Out 超越正常尺寸再收回，同步呈現伸縮、短促旋轉及衰減顫抖；冒出的同時展開槽位，下方列立即平滑推移，`INSERT_DISTURB_COUNT` 範圍內的已顯示列依列距接連疊加 DISTURB，完成後各列停在更新後的位置。失效列由上至下以短間隔接連略微放大、快速縮至零，全程維持原透明度；所有失效列退場後，保留列由上至下接連移向更新後的位置，以 Back Out 回彈並逐漸停穩。各列維持固定字級與原始比例，框形依文字寬度延展；清單按已顯示列緊密排列，新列於對應牌型最後一張卡片到達浮起最高點時顯示並展開槽位。

結算時各列從原始分數開始，王牌貓先保留目標組並同步將其他列降到零。得分列依清單順序接續亮相，聚焦沿用 Hover 的放大、抖動與推開鄰列，場上對應的牌同時浮成扇形。逐組貓牌每次發動時，所有符合的列同時呈現各自的加成及分數放大縮回，清單順序維持結算前的排列；Copy Cat 發動時，在同一列保留已累計分數，直接加入獨立計算的額外得分，以逐位滾動、進位與卡點呈現累加的合計。執行時分數與牌型名稱各有獨立 Label。所有列算完後依清單索引以短間隔接連放大，並於分數數字下層各發射一波發光粒子飛向中央分數場景入帳，來源合計持續保留。完成結算後，清單恢復當前盤面的原始分數，詳見 [結算分數演出](settlement.md)。

## 平時與 Hover 動態

平時各列微幅上下波動，相鄰列錯開相位。Hover 任一列時全體凍結當下的波動偏移，該列立即放大並播放衰減的位移與旋轉抖動，同時將上方列向上、下方列向下擠開，留出 `HOVER_GAP` 間隙。所有讓位同時開始，`HOVER_DISTURB_COUNT` 範圍內的列額外疊加 DISTURB 位移、旋轉及接續節奏，停留時維持放大與間距。兩種條數設定皆以每側計算，預設上下各 3 條；設為 0 時保留排列位移。最近上下各一條使用完整強度，往外每層乘上 `DISTURB_FALLOFF`（預設 0.65），範圍外的列平滑移到目標位置。切換列時前一列縮回、新列播放回饋，全體波動相位持續凍結，上下空間平滑轉移；離開所有列後收回間距並從原相位繼續波動。出場、退場、推移與結算等主要演出控制動畫期間，說明持續可用，平時及 Hover 動態在演出結束後恢復。

## 資料與設定

每個 `combo_entry.gd` Resource 包含 `hand_name` 與 `score`，`score` 保留浮點精度，主要畫面四捨五入顯示整數；執行時另附 `cells`、`direction`、`kind` 與 `breakdown` 明細。將同型別的 Resource 陣列指定給 `combo.entries` 可即時同步整份清單，供開局、換關與結算使用；盤面操作由排程呼叫 `combo.transition_to(entries)` 完成退場與遞補，再逐組呼叫 `combo.reveal(index)`。呼叫 `combo.add_result(hand_name, score)` 可新增一列，`combo.clear_results()` 可清空清單。修改既有 Resource 的名稱或分數會即時更新顯示，保持目前框形及偏移。

顏色、字級、9-slice 邊界、文字留白、列距與偏移範圍集中於 `src/configs/combo/combo_config.gd`。出場、退場、擾動、插入推移、遞補、平時波動與 Hover 參數集中於 `src/configs/combo/combo_animation_config.gd`，主要演出由 `src/scripts/combo/combo_animator.gd` 執行，平時波動及 Hover 由 `src/scripts/combo/combo_idle_animator.gd` 執行。清單位置由 gameplay 中的 combo 場景實例設定。`tests/combo/combo_sequence_test.gd` 驗證既有外觀延續、新列避開兩側造型、偏移範圍、刪除與移位保留外觀，以及固定種子的重現性。

`src/service/combo/group_transition.gd` 負責純資料配對，`tests/combo/group_transition_test.gd` 驗證延續、替換、合併、拆分、交叉方向、列移位及路徑順序。
