# 結算分數演出

`src/scenes/score/settlement_score.tscn` 是中央上方的獨立分數場景，包含大分數、右側 Combo 數量與倍率。`settlement_presenter.gd` 使用單一 Tween 時間軸讀取核心結算事件，依序驅動 Combo 條、貓牌、中央數字與左上關卡分數。所有事件的來源、目標與前後值來自同一份確認結算快照；動畫完成與跳過均提交該份結果一次。貓牌計算規則見 [貓牌系統](cat_card.md)。

## 演出順序與頓點

玩家確認結算後鎖定操作與貓牌排序，Combo 條從原始分數開始。王牌貓先彈跳顯示最高分獨占，保留的目標列放大縮回，其餘列以里程表倒轉至零分並變暗，後續由得分組推進 Combo。新出高牌保底加入中央，依序完成數字滾動、精確終值及到位回饋。接著按照左上清單逐組演出：當前列放大縮回，右側由第一組開始滾入 `1 combo ×1.0`，之後隨得分組更新組數及基本倍率；數量 N 的縮放幅度最大。

每組適用的貓牌依上排左至右、下排左至右發動。來源貓牌短暫放大、輕擺與提亮，浮出本次實際加成；該條分數同步滾動至事件指定的目標，並保留原有放大縮回。每段固定在精確終值並完成回饋，停留 `STEP_HOLD` 後才發動下一段。該組先完成全部貓牌加成與額外計分，條目顯示各次計分的合計，再於數字下層產生一波發光粒子送進中央。每個得分條目每次結算飛分一次，中央小計加入該組完整合計，來源數字保留在原位，再處理下一條。

Copy Cat 發動時，來源貓牌跳動並顯示額外計分提示，該條從已累計分數滾動至加上本次額外得分的合計，再由唯一的 `group_award` 事件送入中央。例如原始 53 分經王牌貓乘至 265 分，Copy Cat 發動後由 265 分累加至 530 分。核心每次額外計分都從原始分數獨立套用逐組效果，將計算明細保存在 `repeat.calculation`；演出讀取 `repeat` 的累計前值、額外得分與累計後值，其他逐組貓牌的動畫集中於第一次計分。Combo 數量維持原值，整次結算的加分、倍率與成長於各自階段發動一次。

所有組完成後，依貓牌順序加入額外總分與 Combo 倍率；來源與目標同步回饋。中央總分乘上最終 Combo 倍率且數值改變時，右側倍率放大縮回，中央滾動至乘算結果。乘算前後相同時直接銜接下一個有效事件；其後逐張發動有效的總分倍率貓牌。最後一次有效的中央跑分直接使用結算完成表演，各種收尾完整結束並停留 `STEP_HOLD` 後，粒子由中央飛往左上關卡面板，抵達後累積分數以里程表更新，進度條同步前進，最後補牌或顯示關卡結果。

中央各段由同一時間軸依序銜接，先顯示前段精確目標、完成一次到位回饋，再開始下一段。共用數值狀態在新段接手時先完成前段目標；重設時同步清除數字輪與卡點狀態。加速同步調整時間軸、數字卡點、填色流場與火焰時鐘。跳過停止時間軸、清除粒子與中央特效、還原 Combo 及貓牌回饋，將最終分數同步至關卡面板並完成一次結算。加速與跳過控制保留於場景的 controls 節點，目前場景設定為隱藏。

## 共用逐位里程表

中央分數、Combo 條分數、Combo 組數、Combo 倍率與左上累積分數共用同一個數字輪元件。加分時舊數字向上離開、新數字由下方升起，依序滾動 0～9，低位進位時帶動高位，減分時沿相同軌跡反向播放。每個移動數字落入定位時微幅壓縮並回正，整段到位另有短促卡點。大分差前段快速推進，末段保留短距離滾動及清楚終值；每幀直接取樣當下輪位，動畫總長度由 config 控制。

數字輪開始滾動時取得該段時間軸長度，並依播放速度換算成實際秒數。前段與尾段各自等速推進，每一位數在各段的平均轉速因此固定；轉速超過 `READABLE_RATE` 的位數改以 `SPIN_RATE` 沿計數方向等速捲動，讓高速滾動清楚呈現向上衝的方向。捲動位置由交接點的實際輪位倒推，轉速回到可讀範圍的段落邊界時精確接上實際數字；整段結束時仍高速的位數直接捲動到終值。等速捲動期間的位數不播放卡點壓縮。

主要分數四捨五入顯示整數，Combo 組數固定為整數，核心計算及過關判定保留完整精度。倍率依該段起點與終點選擇固定的一位或兩位小數：`×1.0 → ×1.5` 全段使用一位，`×1.5 → ×1.75` 全段使用兩位。小數點、前綴與靜態目標分數固定，只有數字輪滾動。新的一段重新依兩端值決定位數。

各數字輪採字型中最寬數字的固定槽寬，單段以起終值的最大位數預留尺寸；高位在進位時出現，整數零顯示單一 0。中央根節點維持編輯器位置，動作套在內部視覺層；右側 Combo 資訊依預留文字寬度及最大表演尺寸配置，撞擊與抖動期間維持位置。字體描邊與填色各自繪製，銀河或全像彩虹作用於填色，深色描邊保留辨識度。

## 一般與高分表演

結算開始時，使用快照的本次最終分數與本關完整目標分數比較：達到 `HIGH_SCORE_RATIO` 倍時採高分表演，預設為 1.5 倍。`FORCE_HIGH_SCORE` 可強制每次結算使用高分表演，方便調整與比較。高分判定只控制演出，計分及過關規則沿用核心結果。

一般結算每段到位時播放短促放大、旋轉與衰減震動，再回到原尺寸；最後一段直接換成強度更大的結算完成回饋。高分結算在跑數字時快速震動，各段到位使用更大的放大、旋轉與震動。

高分結算的最後一段以重物撞擊為節奏，像一座長櫃子被衝上天花板再摔回地面，最主要的力量集中在撞頂那一下。數字到達目標後立刻被衝起，邊上升邊放大並傾斜，以高於平均的速度離地，帶著餘速使最高的角撞上天花板；撞頂瞬間在放大的尺寸上再橫向壓扁，該角固定在天花板上，頓停期間強烈震動並衰減。接著帶著向下初速反彈，邊下墜邊縮回接近原尺寸並轉向另一側，由最低的一個角先著地，輕微壓扁並短暫頓停震動。之後短促彈起，在空中轉向反方向，換另一個角著地；每次彈起的高度、時間與傾斜依 `BOUNCE_DECAY` 遞減，`BOUNCE_COUNT` 次後兩腳同時著地，回到原位與原形。每次著地都由當下最低的角貼住地面，後續著地伴隨逐次減弱的小幅震動。

撞頂與第一個角著地各觸發一次衝擊回饋，天花板與地板分別設定數字震動、畫面震動、閃白、火焰噴發與碎片，預設撞頂最強。多次撞擊的回饋各自淡出並相互疊加。填色在撞擊瞬間變白，回落時經過暖色 `FLASH_TINT` 再回到原填色，描邊保持深色；數字後方可同步亮起逐層擴散的白色光暈，形成過曝感。整個畫面隨撞擊震動，並以畫面中心微幅放大遮住位移露出的邊緣。火焰在撞擊瞬間噴發，升得更高、方塊更大後回到原狀。碎片為方塊，顏色取自目前的填色模式：銀河取較亮的雲霧色、星點色與紫色，全像彩虹取整組彩虹色盤。撞頂時碎片由上緣兩端沿天花板向左右噴出並略往下飄，畫在數字前方；落地時少量碎片由著地的角向上噴出，畫在數字後方，兩者都受重力影響旋轉落下。暖色回落、光暈、畫面震動、火焰噴發與碎片各有獨立開關，閃白固定播放。最後一段的時間軸包含撞擊回饋完整淡出的時間。

高分數字以白色起步，當跑分達到本次最終分數的 `ENERGY_START` 比例時開始漸變，在 `ENERGY_FULL` 比例時達到完整效果。`score_fill_config.gd` 的 `MODE` 選擇 `Mode.GALAXY`（預設銀河）或 `Mode.HOLOGRAPHIC`（全像彩虹）。兩者共用多層雜訊與座標扭曲形成的霧狀流場，整片雲霧快速由右向左流動，局部雲層以較慢的速度翻湧變形。整串數字使用連續的流場座標，描邊、數值與進位規則各自保持穩定。

銀河參考 `src/assets/ref/universe.jpg`：以超深藍為底，明暗淺藍雲霧交錯，少量紫色融入雲層。兩層細小星點以獨立座標向左移動，速度低於雲霧，遠層更慢、更細且較暗，呈現景深；星點具有可調的微幅閃爍。雲霧與星點各自提供速度設定。

全像彩虹參考 `src/assets/ref/rainbow.jpg`，保留獨立模式，使用明亮的粉、紫、天藍、薄荷綠、黃及桃色循環色盤，飽和度略高於粉彩而保持清透。各色在不規則的霧狀色塊中柔和交融，隨快速向左的流場持續翻湧，明亮雲層帶出輕微的全像光澤。配色直接由 config 的色盤控制。

火焰參考 `src/assets/ref/gameplay.png`，完全由重疊方塊組成，分成多層由後往前疊放：最後方是飄到字頂上方的零星淺黃小方點，其次是從橘色後方竄出的淺黃頂冠，再來是從深橘頂緣露出的一條黃橘帶，最前方是包住數字的深橘主體。深橘主體比數字左右略寬，底部略低於字底、頂緣略高於字頂，由大塊方塊密集堆成近乎實心的一片。各層位置以字高為單位，0 為數字字形下緣、1 為字形上緣，字形範圍取自字型中數字的實際字形。每層各自設定顏色、出發與升到頂的高度、寬度、方塊數量、大小、縮小比例、上升時間、加速程度、轉速範圍與橫向散開幅度。方塊由該層底部長出，上升時逐漸加速、縮小並橫向散開，到頂縮小消失，底部緩慢翻動、上方快速竄升；轉速在每層的範圍內各自取值並隨機決定方向，越上層的預設轉得越快。高分漸強以字底為基準等比例縮放整團火焰，各層的出發與到頂高度一起隨漸強進度長高，任何進度下各層都維持滿能量時的相對位置並互相銜接，從貼著字底的小火逐漸長成完整火焰；撞擊噴發拉高各層頂端，底部保持貼住數字；漸強與噴發同時放大方塊。火焰位於數字後方，跟隨數字的撞頂、落地及反彈，共用高分漸強進度。`FIRE_ENABLED` 獨立控制火焰，填色與高分動作各自持續運作。結算結束及跳過時清除填色、閃白、光暈、火焰、碎片與畫面震動狀態。

## 元件與微調設定

`number_motion.gd` 保存精確數值、計數進度與各段推進速率，`odometer_math.gd` 計算倍率小數位、數字輪進位、高速位數的等速捲動與交接、可見位數與卡點，`celebration_math.gd` 計算高分門檻、最後中央事件、高分效果漸強與各段到位姿態，`slam_math.gd` 計算高分最後一段的撞擊時間軸、角落著地與搖晃、碎片噴出點，以及閃白、火焰噴發與畫面震動強度。`odometer/odometer_label.gd` 負責共用數字輪繪製、裁切與描邊，並提供數字字形的上下緣。`score_counter.gd` 管理中央數字的視覺層並驅動撞擊特效，`celebration/score_fill.gd` 依模式建立填色材質、色盤與碎片色盤；`fog.gdshaderinc` 共用霧狀流場，`flash.gdshaderinc` 共用撞擊閃白，`galaxy.gdshader` 與 `rainbow.gdshader` 分別繪製銀河及全像彩虹。`flame_math.gd` 計算火焰各層方塊的位置、大小與角度，`celebration/block_flame.gd` 逐層繪製方塊火焰，`celebration/flash_glow.gd` 繪製閃白光暈，`celebration/impact_debris.gd` 負責撞擊碎片，`celebration/screen_quake.gd` 套用畫面震動。Combo、倍率與關卡元件沿用各自的內容及排版責任。

`score_particles.gd` 以光暈與亮色核心繪製飛分粒子，以緊密出發間距沿弧線形成單波飛行，粒子位於來源數字下層。Combo 至中央、中央至左上共用此元件。`level_board.gd` 分開保存實際分數與顯示分數，粒子抵達後才更新畫面。
