# 商店

每次領取 [過關獎勵](level_reward.md) 後進入商店。商店由貓牌區、轉換牌／任務單／貓點心區、卡包區三個獨立方塊，以及放置持有張數、重骰與「下一關」的操作區組成。貓牌區上架兩張貓牌；轉換牌／任務單／貓點心區與卡包區各保留兩個空卡位，待對應系統完成後接入。按「下一關」後四個方塊依序離場，進入下一關並發牌。

## 上架與機率

每次進入商店重新上架兩格貓牌。每格獨立依權重抽出稀有度：R 70%、SR 25%、SSR 5%，再從該稀有度中尚未持有、也未在另一格上架的貓牌等機率選出一張。抽中的稀有度沒有可上架的貓牌時，先往較低稀有度遞補，再往較高稀有度遞補；例如一條龍與上下舖兩張 SSR 都持有後，抽到 SSR 的格子改從 SR 選出。不重骰時，一次商店出現 SSR 的機率約 9.75%，至少出現一張 SR 約 44%。商店使用獨立於牌庫的亂數，固定種子可重現上架結果。

## 價格與買賣

每張貓牌各有固定買價，賣價依稀有度：R 2 元、SR 4 元、SSR 6 元。

| 稀有度 | 買價  | 貓牌                                                                                         |
| ------ | ----: | -------------------------------------------------------------------------------------------- |
| R      |  6 元 | 同點貓、交錯貓、連擊貓、成雙貓、紅黑貓、長大貓、勤勞貓                                       |
| R      |  5 元 | 安穩貓、百變貓、同花貓、長尾貓、留一手、換手貓、節省貓、連順貓、繁花貓、滿堂貓、四喜貓、排排貓 |
| SR     |  9 元 | 小巧貓、各有所長、圍圈貓、緊湊貓                                                             |
| SR     |  8 元 | 獨奏貓、Copy Cat、王牌貓、收編貓、群島貓、六張貓                                             |
| SSR    | 13 元 | 一條龍、上下舖                                                                               |

金錢足夠且持有未滿五張時可購買，按鈕顯示「$N 購買」；買下的貓牌排在貓牌區最後，原格顯示已售出直到重骰。金錢不足時按鈕停用並以警示色顯示價格，持有五張時按鈕顯示「已達上限」。勤勞貓等整局累積的效果讀取核心自開局記錄的操作數，購買當下即追溯生效。

賣出在操作階段與商店期間都可進行：點擊貓牌後，卡片下緣彈出「賣出 $N」，按下即賣出並移除該貓牌的效果，分數預覽與場上容量隨之更新；再點同一張或點擊其他位置會收起按鈕。結算演出、發牌、卡牌動作與牌型回饋期間貓牌區鎖定，按鈕隨之收起。

## 重骰

重骰只刷新貓牌區，兩格一起重新上架，已售出的格子一併補上。每次進入商店從 3 元起算，每重骰一次增加 1 元。

## 演出

商店開啟時遮罩淡入，貓牌區與頂部資訊列提升到遮罩上方，方便賣牌與查看金錢。四個方塊依序從下方帶傾角衝入，衝過頭一點後煞回原位並壓扁回彈；每個方塊抵達時，區內商品接連往上跳一下，之後以錯開的相位持續上下浮動，形成波浪。

購買時金幣從右上金錢飛進商品格，金錢數字轉紅跳動；卡片同時放大抬起，沿弧線旋轉一圈飛到貓牌區的新位置，落地後從零彈出並旋轉抖動，已售出的格子同時彈跳。重骰時重骰按鈕彈跳，金幣飛進按鈕，兩張貓牌翻面收起、換上新貨後翻回並依序跳動。賣出時卡片往上彈起放大，再旋轉縮小消失，同時噴出金幣飛進金錢，其餘貓牌平滑滑到新位置。離場時四個方塊依序往下掉出，遮罩淡出。

## 設定與結構

| 檔案                                     | 責任                                           |
| ---------------------------------------- | ---------------------------------------------- |
| `configs/shop/shop_config.gd`            | 格數、重骰費用、稀有度權重、買價與賣價。       |
| `configs/shop/shop_view_config.gd`       | 文字、排版、圖層與演出參數。                   |
| `configs/cat_cards/cat_trade_config.gd`  | 賣出按鈕、賣出消失、購買彈出與重新排列。       |
| `service/shop/cat_market.gd`             | 價格查詢與依稀有度上架。                       |
| `service/shop/shop_state.gd`             | 本次商店的上架內容與重骰次數。                 |
| `service/gameplay/run_state.gd`          | 開店、購買、重骰與賣出的資格判定及金錢收付。   |
| `service/cat_cards/cat_loadout.gd`       | 加入、移除貓牌與持有上限。                     |
| `scenes/shop/shop.tscn`                  | 商店場景，四個方塊的位置與尺寸可在編輯器調整。 |
| `scripts/shop/`                          | 商店、方塊與商品格的呈現。                     |
| `scripts/cat_card_area/cat_card_area.gd` | 賣出按鈕、賣出消失與剩餘貓牌重新排列。         |

`tests/shop/cat_market_test.gd` 驗證每張貓牌的價格、稀有度遞補順序、排除已持有與重複上架、固定種子可重現，以及抽樣分布符合權重與遞補；`tests/shop/shop_flow_test.gd` 驗證開店上架、重骰費用遞增與每次開店重置、購買與賣出的金額、持有上限、操作階段賣出即移除效果，以及重新購買保留整局操作累積。
