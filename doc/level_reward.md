# 過關獎勵

Lv 1～20 達到目標分數時，核心依過關當下的狀態計算過關獎勵並立即加入金錢，畫面接著顯示過關獎勵，按「進入商店」後前往 [商店](shop.md)。Lv 21 達標結束整場遊戲，沿用結果畫面顯示通關；敗北同樣使用結果畫面並提供重新開始。

## 收入計算

獎勵明細依序為過關獎勵、貓牌獎勵、速通獎勵、任務單獎勵與利息，總額為各項相加。數值集中於 `src/configs/level_reward/reward_config.gd`。

| 項目     | 金額                                                   | 設定                             |
| -------- | ------------------------------------------------------ | -------------------------------- |
| 過關獎勵 | 每關 3 元                                              | `BASE`                           |
| 速通獎勵 | 過關當下每剩 1 次結算給 1 元，最多 5 元                | `SPEED_PER_SETTLEMENT`           |
| 利息     | 加入本關獎勵前的持有金錢每滿 5 元給 1 元，最多 4 元    | `INTEREST_STEP`、`INTEREST_CAP`  |

利息以過關當下的持有金錢計算，本關中途入帳的金錢一併計息，本關獎勵從下一次過關開始計息。例如持有 12 元、剩 3 次結算時過關，收入為 3 + 3 + 2 = 8 元，持有 20 元以上即拿滿 4 元利息。

貓牌與任務單的獎勵由各自系統以 `{"id", "amount"}` 傳給 `level_reward.gd`，貓牌獎勵排在過關獎勵之後，任務單獎勵排在速通獎勵之後，畫面以貓牌名稱或「任務單」標示。目前的貓牌都在結算時作用於分數，任務單尚未開放，因此明細為過關獎勵、速通獎勵與利息三列。關卡中途給錢的效果在觸發當下直接入帳。

## 畫面與演出

`src/scenes/level_reward/level_reward.tscn` 以遮罩覆蓋整個畫面，頂部資訊列提升到遮罩上方，讓金錢入帳全程可見。面板顯示「Lv N 過關！」、本關分數與目標、各項明細、本關收入合計及「進入商店」按鈕；速通明細附註剩餘結算次數，利息明細附註計息的持有金錢。面板中心由 `pivot` 節點決定，預設與商店四個方塊的中心對齊，可在編輯器調整位置，面板依內容自動撐開。

演出依序為：遮罩淡入，面板從上方帶傾角急速落下，落地時壓扁再彈性回彈；標題從零彈出並旋轉抖動。明細逐列從左側滑入煞停，金額放大回彈，同時噴出金幣沿弧線飛進右上金錢，每枚金幣抵達時金錢數字跳動放大並亮起、金錢圖示彈跳抖動、落點擴散一圈光環，合計同步累加；零元的列淡為次要資訊。全部金幣落定後合計放大抖動，「進入商店」接著彈出並持續呼吸。演出期間點擊畫面以加速播放；按下「進入商店」後面板往上飛出、遮罩淡出，再開啟商店。

文字、字級、時間與強度集中於 `src/configs/level_reward/reward_view_config.gd`，面板與按鈕配色與商店共用 `src/configs/ui/ui_palette.gd`，金幣飛行與金錢跳動集中於 `src/configs/money/money_motion_config.gd`。

## 結構與測試

| 檔案                                    | 責任                                                       |
| --------------------------------------- | ---------------------------------------------------------- |
| `service/level_reward/level_reward.gd`  | 計算獎勵明細與總額。                                       |
| `service/gameplay/run_state.gd`         | 過關時計算並入帳，`reward` 保存本關明細，進入下一關時清空。 |
| `scripts/level_reward/level_reward.gd`  | 面板演出、加速播放與進入商店。                             |
| `scripts/level_reward/reward_row.gd`    | 明細列的滑入與金額彈出。                                   |
| `scripts/money/coin_flight.gd`          | 金幣噴出、翻面飛行與落點光環，與商店購買、賣出共用。       |
| `scripts/gameplay/economy_presenter.gd` | 串接過關獎勵、商店、買賣與頂部金錢顯示。                   |

`tests/level_reward/level_reward_test.gd` 驗證各項金額、利息取整與上限、明細順序、貓牌與任務單接口、過關入帳，以及最終關結束整場時金錢維持不變。
