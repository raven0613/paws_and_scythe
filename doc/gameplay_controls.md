# 鏡頭控制、牌庫與金錢

鏡頭按鈕及資源圖示以 `src/assets/gameplay.png` 的 1152 × 648 參考畫面配置。`src/scenes/gameplay_controls/camera_controls.tscn` 放在右側黑色區域的左下斜邊旁，`resources_display.tscn` 放在其左上方的頂部資訊列。兩者皆在 gameplay 中實例化，整組位置可於編輯器調整。

## 鏡頭按鈕與背景輸入

四顆按鈕由上往下為 Auto、Reset、Zoom In、Zoom Out，使用 `btn_zoom_auto`、`btn_zoom_reset`、`btn_zoom_in`、`btn_zoom_out` 素材。Auto 預設亮起，表示開啟追蹤；關閉時調暗。Zoom In／Out 以安全適配區中心平滑縮放，連續點擊累加目標倍率，並從當前顯示狀態接續補間。Reset 執行一次完整適配並維持 Auto 狀態。

牌陣覆蓋整個背景，四周黑邊與右側 Boss 黑塊位於牌陣上層。可見範圍隨黑塊實際形狀呈現，手動移動及放大時可利用全部露出的背景。黑塊的輸入遮罩使用同一框線尺寸與 Boss 背景素材透明度，遮住的牌與待放格也會被遮罩阻擋點擊。

Auto 與 Reset 共用完整適配計算：範圍包含所有實體牌與所有合法 placement，即使待放格當下隱藏仍納入。先依畫面尺寸換算 `gameplay_frame_config.gd` 的 `CLEAR_RECT`，取右側斜邊內完全露出的區域，再排除固定介面的矩形範圍，選取最大的可用矩形，四周保留 `board_config.gd` 的 `VIEW_PADDING`。完整牌陣置中於此區域並縮放至全部可見；自動適配最多使用原始尺度，極長或分離的牌陣可繼續縮小以完整入鏡。這個安全區只用於計算鏡頭目標，牌陣的繪製範圍覆蓋完整背景。

`src/scripts/board/board_camera_input.gd` 統一處理鏡頭輸入。滑鼠滾輪與 Mac 觸控板雙指捲動以游標為錨點縮放，觸控板捏合使用原生放大手勢；卡牌上的縮放手勢也適用。在卡牌、可操作待放格與固定 UI 以外的背景，按住左鍵或中鍵可平移，拖曳可延伸至起始區域之外。按鈕縮放使用短暫補間，連續手勢則逐次更新倍率以跟隨手指。

手機透過原始觸控位置計算雙指距離與中點，捏合時保持中點下的世界座標，並隨兩指中點移動。鏡頭手勢由牌陣可見背景或場上卡牌／待放格開始，固定 UI 保留原有輸入。牌陣上的單指點按在放開時確認，雙指操作結束後兩根手指都不會觸發選牌或放牌；系統取消觸控、遊戲暫停輸入或視窗失去焦點時清除手勢狀態。原始觸控與其模擬滑鼠事件共用一次操作判定。

手動調整鏡頭後維持當前視角，開啟 Auto 時於下一次牌陣結構變動重新適配；關閉 Auto 後由手動操作控制。重新開啟 Auto 立即適配。發牌與結算期間暫停鏡頭操作，完成後恢復輸入。`board_camera.gd` 管理鏡頭補間與目標，`board_view_area.gd` 處理可操作範圍與固定介面位置，`board_layout.gd` 負責適配、縮放及錨點數學，`board_touch.gd` 負責觸控狀態。鏡頭縮放幅度、觸控板靈敏度、點按移動容許距離與動畫時間集中於 `src/configs/board/board_config.gd`。

## 牌庫與金錢

牌庫使用 `icon_deck`，旁邊顯示抽牌堆實際剩餘張數。金錢使用 `icon_money`，每場開始時讀取 `src/configs/gameplay/game_rules.gd` 的 `STARTING_MONEY`，目前為 5。金錢跨關保留，重新開始一場遊戲時重置；本版提供數值與顯示，交換及挖牌的成本維持扣分規則。

`src/scripts/gameplay_controls/resources_display.gd` 負責數量及顏色。圖示保留素材的原始明暗，預設使用參考圖的藍色 `#6A98E8` 與金黃色 `#EEC445`。`controls_config.gd` 集中管理預設顏色、關閉狀態透明度、Hover 亮度與字級；場景另外提供可調整的顏色屬性，方便背景主題切換時同步換色。

## 逐張發牌

開局、跨關、結算補滿手牌及棄牌補抽皆使用同一個發牌流程。`run_state.gd` 的 `last_draw` 記錄最近一次實際抽牌的卡牌 ID 與逐張抽出後的剩餘數量，支援棄牌堆洗回時的連續抽牌。即使洗回後補抽到同一張卡，也會記錄該次抽牌，供畫面正確呈現。

`src/scripts/hand_area/hand_dealer.gd` 將實際卡牌實例放在牌庫圖示中心，依序由小長大，再快速飛向對應的手牌槽位，落定時恢復原尺寸。每張牌出發時同步更新牌庫數字，牌面與附加圖層沿用同一個實例。發牌期間鎖定遊戲操作，全部落定後恢復。一般撤銷將原牌還回手牌，由撤銷流程更新位置。

`src/configs/hand_area/deal_config.gd` 定義逐張間隔、生長時間、飛行時間與縮放比例。開局六張牌的出發間隔為 0.07 秒，每張生長 0.09 秒、飛行 0.22 秒，前後張的動畫交疊，形成連續俐落的發牌節奏。

目前主畫面以關卡面板、Combo 清單、操作按鈕、牌庫與金錢圖示及四顆鏡頭按鈕呈現資訊。其他盤面數量、手牌上限及淨分預覽等資訊的視覺呈現留待後續設計，計分與限制持續由核心流程管理。`tests/gameplay/draw_events_test.gd` 驗證金錢生命週期及抽牌事件，`tests/board/board_rules_test.gd` 驗證放牌幾何，`tests/board/camera_math_test.gd` 驗證安全區、待放格適配、縮放錨點與觸控狀態。
