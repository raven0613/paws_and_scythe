# 鏡頭控制與頂部資訊列

鏡頭按鈕及資源圖示以 `src/assets/gameplay.png` 的 1152 × 648 參考畫面配置。`src/scenes/gameplay_controls/camera_controls.tscn` 放在右側黑色區域的左下斜邊旁，`resources_display.tscn` 放在其左上方的頂部資訊列。兩者皆在 gameplay 中實例化，整組位置可於編輯器調整。

## 鏡頭按鈕與背景輸入

四顆按鈕由上往下為 Auto、Reset、Zoom In、Zoom Out，使用 `btn_zoom_auto`、`btn_zoom_reset`、`btn_zoom_in`、`btn_zoom_out` 素材。Auto 預設亮起，表示開啟追蹤；關閉時調暗。Zoom In／Out 以安全適配區中心平滑縮放，連續點擊累加目標倍率，並從當前顯示狀態接續補間。Reset 執行一次完整適配並維持 Auto 狀態。

牌陣覆蓋整個背景，四周黑邊與右側 Boss 黑塊位於牌陣上層。可見範圍隨黑塊實際形狀呈現，手動移動及放大時可利用全部露出的背景。黑塊的輸入遮罩使用同一框線尺寸與 Boss 背景素材透明度，遮住的牌與待放格也會被遮罩阻擋點擊。

Auto 與 Reset 共用完整適配計算：範圍包含所有實體牌與所有合法 placement，即使待放格當下隱藏仍納入。先依畫面尺寸換算 `gameplay_frame_config.gd` 的 `CLEAR_RECT`，取右側斜邊內完全露出的區域，再排除固定介面的矩形範圍，選取最大的可用矩形，四周保留 `board_config.gd` 的 `VIEW_PADDING`。完整牌陣置中於此區域並縮放至全部可見；自動適配最多使用原始尺度，極長或分離的牌陣可繼續縮小以完整入鏡。這個安全區只用於計算鏡頭目標，牌陣的繪製範圍覆蓋完整背景。

`src/scripts/board/board_camera_input.gd` 統一處理鏡頭輸入。滑鼠滾輪與 Mac 觸控板雙指捲動以游標為錨點縮放，觸控板捏合使用原生放大手勢；卡牌上的縮放手勢也適用。在卡牌、可操作待放格與固定 UI 以外的背景，按住左鍵或中鍵可平移，拖曳可延伸至起始區域之外。按鈕縮放使用短暫補間，連續手勢則逐次更新倍率以跟隨手指。

手機透過原始觸控位置計算雙指距離與中點，捏合時保持中點下的世界座標，並隨兩指中點移動。鏡頭手勢由牌陣可見背景或場上卡牌／待放格開始，固定 UI 保留原有輸入。牌陣上的單指點按在放開時確認，雙指操作結束後兩根手指都不會觸發選牌或放牌；系統取消觸控、遊戲暫停輸入或視窗失去焦點時清除手勢狀態。原始觸控與其模擬滑鼠事件共用一次操作判定。

手動調整鏡頭後維持當前視角，開啟 Auto 時於下一次牌陣結構變動重新適配；關閉 Auto 後由手動操作控制。重新開啟 Auto 立即適配。發牌、結算與放牌、交換、挖牌、棄牌動作期間暫停鏡頭操作，完成後恢復輸入；後續牌型成立與消失回饋期間開放手動鏡頭操作。放牌、交換、挖牌、棄牌與撤銷演出固定當前鏡頭，動作完成後依自動追蹤設定恢復適配。`board_camera.gd` 管理鏡頭補間與目標，`board_view_area.gd` 處理可操作範圍與固定介面位置，`board_layout.gd` 負責適配、縮放及錨點數學，`board_touch.gd` 負責觸控狀態。鏡頭縮放幅度、觸控板靈敏度、點按移動容許距離與動畫時間集中於 `src/configs/board/board_config.gd`。

## 場上張數、牌庫與金錢

頂部資訊列由左至右呈現場上張數、牌庫與金錢。場上張數以純數字「目前張數/實際上限」顯示，例如 `0/20`，持有緊湊貓時為 `0/15`；數字計入所有留在牌陣的實體卡牌，放牌、挖牌、撤銷與換關時同步更新。分母使用核心當前容量上限。張數達到上限時以右緣為軸彈跳並旋轉抖動一次，接著轉為警示色，以呼吸節奏在亮暗之間持續閃爍，低於上限時恢復原色；場上已滿時嘗試拖曳手牌也會彈跳一次。警示色、閃爍週期與彈跳參數為 `controls_config.gd` 的 `BOARD_FULL_*` 與 `BOARD_ALERT_*`。牌庫使用 `icon_deck`，旁邊顯示抽牌堆實際剩餘張數。金錢使用 `icon_money`，每場開始時讀取 `src/configs/gameplay/game_rules.gd` 的 `STARTING_MONEY`，目前為 5。金錢跨關保留，重新開始一場遊戲時重置；收入來自 [過關獎勵](level_reward.md) 與賣出貓牌，支出為 [商店](shop.md) 的購買與重骰，交換及挖牌的成本維持扣分規則。金錢變動時數字跳到新數值並放大回彈，增加時亮起、減少時短暫轉紅，金錢圖示同時彈跳並旋轉抖動；過關獎勵與賣出時金幣飛入金錢，購買與重骰時金幣從金錢飛向商品。數字跳動與金幣飛行的參數集中於 `src/configs/money/money_motion_config.gd`。

`src/scripts/gameplay_controls/resources_display.gd` 負責數量及顏色。圖示保留素材的原始明暗，預設使用參考圖的藍色 `#6A98E8` 與金黃色 `#EEC445`。`controls_config.gd` 集中管理預設顏色、關閉狀態透明度、Hover 亮度、字級、場上張數格式與滿格警示；場景另外提供可調整的顏色屬性，方便背景主題切換時同步換色。

## 放牌、交換、挖牌與棄牌演出

放牌成功後，原卡牌從手牌選取時抬高的位置出發，右側手牌同時開始補位：由最靠近空位的一張起，每隔 `SHIFT_INTERVAL` 依序以 Cubic Out 在 `SHIFT_DURATION` 內滑向左側槽位，手牌底板右緣跟隨最後一張移動的牌收回。出牌卡牌以 0.26 秒臨界阻尼彈簧響應飛往點選的盤面格子，快速起步後在格子上方減速，尺寸同步過渡至當前牌陣縮放比例。飛行同時模擬離開桌面的高度：前段快速升起，牌面放大、陰影拉遠並往上抬，在飛行進度 `PLACE_APEX` 時最高，之後加速落下，抵達的瞬間以最快速度拍上格子，牌面先壓小再 Q 彈回原尺寸，陰影同時收回貼齊牌面。落定後將同一卡牌移交盤面並刷新牌型清單，仍在補位的手牌接續滑到各自的槽位。飛行期間固定鏡頭與目標格位置，落定後依自動追蹤設定恢復適配。

拖曳放牌時，手牌區保留原槽位，卡牌在 `LIFT_DURATION` 內以 Back Out 浮起到離開桌面的高度，牌面放大、陰影拉遠，以每秒 `FOLLOW_SPEED` 的指數速率追上游標並維持按下時的相對位置。卡牌依橫向速度以 `SWAY_PER_SPEED` 傾斜，上限 `MAX_SWAY`，同時沿用共用飛行形變依移動速度伸縮傾身。游標鎖定待放格時該格放大亮起，牌面以同樣的補間下壓到 `TARGET_LIFT`，位置往格子中心靠攏 `MAGNET` 比例；離開時升回。放開後由放開時的位置、高度與擺動角度接續：落入待放格時以臨界阻尼彈簧在 `DROP_DURATION` 內移到格子，高度加速降到桌面、角度回正、尺寸過渡至牌陣縮放，拍上時播放放牌的落地回彈，右側手牌同時逐張補位；未落在待放格時在 `DRAG_RETURN_DURATION` 內飛回原槽位，以輕量回彈落定。拖曳參數集中於 `src/configs/hand_area/card_drag_config.gd`，落牌與飛回時間在 `action_animation_config.gd`。浮起、跟隨、擺動與拖曳形變由 `src/scripts/motion/card_carry.gd` 提供，貓牌拖曳排序共用同一份動作，詳見 [貓牌系統](cat_card.md#拖曳排序)。

交換成功後，兩張實體牌沿相反側的弧線同時移往對方位置，以 0.3 秒完成起步加速、到位減速及輕微傾斜。挖牌成功後，目標牌立即抖動 0.08 秒，再以拋物線退場：上彈高度為牌高的三分之一，上升速度逐漸降低，頂點垂直速度為零，下落隨重力加速；橫向隨機朝左或右等速移動，整段位移為一個牌寬。卡牌全程保持不透明，持續加速下落，直到旋轉後整張牌越過視窗底部才收起。下落時間依卡牌起點、鏡頭縮放、視窗底部與旋轉後牌面邊界計算；位移使用卡牌所在座標系的尺寸，隨牌陣鏡頭縮放保持比例。

棄牌沿用選取時的卡牌位置，朝畫面左下方加速飛出並輕微旋轉，單張飛行 0.32 秒，多張出發間隔為 0.045 秒。棄出的槽位由補抽的牌原位遞補，其餘手牌維持原槽位；牌庫不足以補滿時，空出的槽位在牌離手時開始以出牌相同的逐張補位收攏。全部選定牌退場後刷新手牌，再由右上牌庫執行既有逐張補牌動畫，同一張牌經洗牌再次抽回時，也依序完成退場與補牌。

`src/scripts/playing_card/card_action_animator.gd` 負責卡牌位置、角度、透明度與圖層演出，使用原卡牌實例並在完成後還原視覺狀態，供撤銷或再次抽回使用。手牌補位與讓位由 `src/scripts/hand_area/hand_area.gd` 補間各張的橫向位置與底板右緣，選取位移與 Hover 在補位期間照常運作；`src/service/hand_area/hand_shift.gd` 計算移動的牌、目標槽位與逐張延遲，補位時間與間隔集中於 `src/configs/hand_area/hand_area_config.gd` 的 `SHIFT_DURATION`、`SHIFT_INTERVAL`。`src/configs/playing_card/action_animation_config.gd` 集中管理動作時間、撤銷速度、撤銷讓位時間、弧線、抖動、拋物線、退場邊距與棄牌淡出參數。`DIG_EJECT_SPEED` 為拋物線彈出倍率，預設 1.3；`DIG_SPEED` 為含抖動的整段挖牌倍率，預設 1。實際抖動時間為原時間除以 `DIG_SPEED`，拋物線時間為原時間除以兩個倍率的乘積，軌跡與終點保持一致。挖牌方向使用獨立的演出亂數來源，牌庫沿用核心亂數序列。遊戲控制器在核心操作成功後鎖定輸入，等動作完成再刷新盤面、牌型清單與鏡頭；棄牌的鎖定持續到補牌完成。放牌、交換、挖牌及撤銷更新盤面後銜接 [牌型成立與消失回饋](group_feedback.md)，期間保留手牌選取、說明與鏡頭輸入，完成後恢復盤面及計分操作。費用、額度與歷史紀錄由核心成功操作一次提交，撤銷依既有規則還原。

撤銷依核心歷史的後進先出順序播放：出牌以放牌相同的升起與落下高度飛回還原後的手牌槽位，右側手牌在飛行開始時同時以 Cubic Out 讓位，手牌底板右緣同步伸展；交換沿原本的兩側弧線反向回到原格；挖牌沿當次保存的拋物線與左右方向倒放，從畫面下方經頂點回到原格。鏡頭已移動時，挖牌回程沿同一拋物線向下延伸起點，讓卡牌由當前畫面下方進場。挖牌軌跡由演出層保存，撤銷後釋放，結算、換關及重開時清空。撤銷出牌預設 0.24 秒、手牌讓位 0.18 秒，交換預設 0.3 秒，挖牌回程另乘 `UNDO_DIG_SPEED`（預設 1.3）。動畫完成後刷新盤面與牌型；棄牌與補抽維持立即確認的結果，後續撤銷還原先前的出牌、交換或挖牌。

## 逐張發牌

開局、跨關、結算補滿手牌及棄牌補抽皆使用同一個發牌流程。`run_state.gd` 的 `last_draw` 記錄最近一次實際抽牌的卡牌 ID 與逐張抽出後的剩餘數量，支援棄牌堆洗回時的連續抽牌。即使洗回後補抽到同一張卡，也會記錄該次抽牌，供畫面正確呈現。

`src/scripts/hand_area/hand_dealer.gd` 將實際卡牌實例放在牌庫圖示中心，依序由小長大，再以臨界阻尼彈簧響應快速飛向對應的手牌槽位，到站時恢復原尺寸，接著固定位置播放輕量落地回彈，輕壓一下再 Q 彈回原形。每張牌出發時同步更新牌庫數字，牌面與附加圖層沿用同一個實例。發牌期間鎖定遊戲操作，全部落定後恢復。撤銷出牌由撤銷流程將原牌飛回手牌。

`src/configs/hand_area/deal_config.gd` 定義逐張間隔、生長時間、飛行時間與縮放比例。開局六張牌的出發間隔為 0.07 秒，每張生長 0.09 秒、飛行 0.22 秒，前後張的動畫交疊，形成連續俐落的發牌節奏。

目前主畫面以關卡面板、Combo 清單、操作按鈕、場上張數與上限、牌庫與金錢圖示及四顆鏡頭按鈕呈現資訊。數量與限制取自核心狀態，牌庫數字依逐張發牌事件更新，場上張數依盤面刷新。`tests/gameplay/draw_events_test.gd` 驗證金錢生命週期及抽牌事件，`tests/hand_area/hand_shift_test.gd` 驗證出牌補位的移動對象、目標槽位、由空位起逐張遞增的延遲與底板跟隨時間，以及棄牌原位遞補、多個空位與撤銷同時讓位，`tests/board/board_rules_test.gd` 驗證放牌幾何，`tests/board/camera_math_test.gd` 驗證安全區、待放格適配、縮放錨點與觸控狀態。

## 共用飛行形變

抽牌、放牌、拖曳與落牌、棄牌、交換、三種撤銷及貓牌拖曳排序共用飛行形變。形變作用於卡牌 `group_visual()` 提供的整體節點，遊戲牌為 `visual`，貓牌為包住卡面的 `carry`，牌面、文字、花紋、陰影與附加圖層作為一個整體一起變形；離開桌面的陰影偏移作用於 `group_shadow()`。每次更新時，依牌中心在畫面上的實際位移換算當下速度，並換算至 `gameplay_frame_config.gd` 的基準畫面；視窗整體縮放維持相同強度，牌陣鏡頭縮放則反映在可見速度中。整張牌沿當下的移動方向拉長、垂直方向等比例變窄，面積維持不變；方向跟隨實際軌跡，沿弧線飛行時一路轉向。速度達 `FULL_SPEED` 時拉長 `MAX_STRETCH`，起飛加速時拉長、最快時最長、減速時跟著收回，停下時回到原形。牌面同時依速度透視傾身，前緣往遠離鏡頭的方向壓低，像被甩出去，傾身使用與 Hover 相同的透視傾斜。

抵達目的地的動作在到站後播放落地回彈：牌面先壓小，再以衰減振盪 Q 彈回原尺寸；到站時殘留的伸縮與傾身隨同一振盪反向擺動後收回，帶著速度抵達的牌（例如挖牌回程）會先壓扁再彈回。放牌與拖曳落入待放格使用較重的 `PLACE_LANDING`；抽牌、交換、拖曳飛回手牌、撤銷出牌、撤銷交換與撤銷挖牌使用較輕的 `LIGHT_LANDING`；拖曳中只套用飛行形變；棄牌飛出畫面，只播放飛行形變。普通挖牌沿用抖動與重力拋物線。

`src/configs/playing_card/flight_animation_config.gd` 集中管理共用形變、高度、落地回彈與彈簧參數；各動作的時間與軌跡由動作及發牌 config 管理，放牌高度的最高點與抬起距離為 `action_animation_config.gd` 的 `PLACE_APEX`、`PLACE_ARC_HEIGHT`。`card_flight.gd` 管理每張卡牌的形變生命週期：飛行中依速度套用伸縮與傾身，並疊加放牌的高度；到站後在同一時間線上銜接落地回彈，完成後還原整體節點、陰影與透視。`flight_math.gd` 與 `dig_motion.gd` 提供純計算，核心測試驗證彈簧終點、速度換算、伸縮維持中心與面積、高度曲線的快速升起與加速落下、落地回彈的先壓下再回彈與停穩，以及拋物線軌跡。

| 設定 | 用途 |
| --- | --- |
| `DRAW_ENABLED`、`PLACE_ENABLED`、`DISCARD_ENABLED`、`SWAP_ENABLED` | 各動作的飛行形變與落地回彈開關，預設開啟。 |
| `DRAG_ENABLED`、`DROP_ENABLED` | 手牌與貓牌拖曳中的飛行形變，以及放開後落入待放格、飛回手牌或吸入貓牌空位的形變與落地回彈開關，預設開啟。 |
| `UNDO_PLACE_ENABLED`、`UNDO_SWAP_ENABLED`、`UNDO_DIG_ENABLED` | 各撤銷動作的飛行形變與落地回彈開關，預設開啟。 |
| `SPRING_RESPONSE` | 抽牌、放牌、交換及出牌／交換撤銷的彈簧反應速度。 |
| `FULL_SPEED`、`MAX_STRETCH` | 達到最大形變的基準畫面速度（像素/秒）與沿移動方向的拉長比例。 |
| `MAX_LEAN`、`LEAN_PERSPECTIVE` | 最大傾身弧度與傾身的透視距離。 |
| `LIFT_SCALE`、`LIFT_SHADOW` | 高度最高時的牌面放大比例與陰影偏移。 |
| `PLACE_LANDING`、`LIGHT_LANDING` | 落地回彈的時間、壓下幅度、振盪次數與衰減。 |
