# 鏡頭控制與頂部資訊列

鏡頭按鈕及資源圖示以 `src/assets/gameplay.png` 的 1152 × 648 參考畫面配置。`src/scenes/gameplay_controls/camera_controls.tscn` 放在右側黑色區域的左下斜邊旁，`resources_display.tscn` 放在其左上方的頂部資訊列。兩者皆在 gameplay 中實例化，整組位置可於編輯器調整。

## 鏡頭按鈕與背景輸入

四顆按鈕由上往下為 Auto、Reset、Zoom In、Zoom Out，使用 `btn_zoom_auto`、`btn_zoom_reset`、`btn_zoom_in`、`btn_zoom_out` 素材。Auto 預設亮起，表示開啟追蹤；關閉時調暗。Zoom In／Out 以安全適配區中心平滑縮放，連續點擊累加目標倍率，並從當前顯示狀態接續補間。Reset 執行一次完整適配並維持 Auto 狀態。

牌陣覆蓋整個背景，四周黑邊與右側 Boss 黑塊位於牌陣上層。可見範圍隨黑塊實際形狀呈現，手動移動及放大時可利用全部露出的背景。黑塊的輸入遮罩使用同一框線尺寸與 Boss 背景素材透明度，遮住的牌與待放格也會被遮罩阻擋點擊。

Auto 與 Reset 共用完整適配計算：範圍包含所有實體牌與所有合法 placement，即使待放格當下隱藏仍納入。先依畫面尺寸換算 `gameplay_frame_config.gd` 的 `CLEAR_RECT`，取右側斜邊內完全露出的區域，再排除固定介面的矩形範圍，選取最大的可用矩形，四周保留 `board_config.gd` 的 `VIEW_PADDING`。完整牌陣置中於此區域並縮放至全部可見；自動適配最多使用原始尺度，極長或分離的牌陣可繼續縮小以完整入鏡。這個安全區只用於計算鏡頭目標，牌陣的繪製範圍覆蓋完整背景。

`src/scripts/board/board_camera_input.gd` 統一處理鏡頭輸入。滑鼠滾輪與 Mac 觸控板雙指捲動以游標為錨點縮放，觸控板捏合使用原生放大手勢；卡牌上的縮放手勢也適用。在卡牌、可操作待放格與固定 UI 以外的背景，按住左鍵或中鍵可平移，拖曳可延伸至起始區域之外。按鈕縮放使用短暫補間，連續手勢則逐次更新倍率以跟隨手指。

手機透過原始觸控位置計算雙指距離與中點，捏合時保持中點下的世界座標，並隨兩指中點移動。鏡頭手勢由牌陣可見背景或場上卡牌／待放格開始，固定 UI 保留原有輸入。牌陣上的單指點按在放開時確認，雙指操作結束後兩根手指都不會觸發選牌或放牌；系統取消觸控、遊戲暫停輸入或視窗失去焦點時清除手勢狀態。原始觸控與其模擬滑鼠事件共用一次操作判定。

手動調整鏡頭後維持當前視角，開啟 Auto 時於下一次牌陣結構變動重新適配；關閉 Auto 後由手動操作控制。重新開啟 Auto 立即適配。發牌、結算與卡牌動作演出期間暫停鏡頭操作，完成後恢復輸入。放牌、交換、挖牌與棄牌演出固定當前鏡頭，動作完成後依自動追蹤設定恢復適配。`board_camera.gd` 管理鏡頭補間與目標，`board_view_area.gd` 處理可操作範圍與固定介面位置，`board_layout.gd` 負責適配、縮放及錨點數學，`board_touch.gd` 負責觸控狀態。鏡頭縮放幅度、觸控板靈敏度、點按移動容許距離與動畫時間集中於 `src/configs/board/board_config.gd`。

## 場上張數、牌庫與金錢

頂部資訊列由左至右呈現場上張數、牌庫與金錢。場上張數以純數字「目前張數/實際上限」顯示，例如 `0/20`，持有緊湊貓時為 `0/15`；數字計入所有留在牌陣的實體卡牌，放牌、挖牌、撤銷與換關時同步更新。分母使用核心當前容量上限，操作期間依實際張數呈現，容量判定時機沿用結算規則。牌庫使用 `icon_deck`，旁邊顯示抽牌堆實際剩餘張數。金錢使用 `icon_money`，每場開始時讀取 `src/configs/gameplay/game_rules.gd` 的 `STARTING_MONEY`，目前為 5。金錢跨關保留，重新開始一場遊戲時重置；本版提供數值與顯示，交換及挖牌的成本維持扣分規則。

`src/scripts/gameplay_controls/resources_display.gd` 負責數量及顏色。圖示保留素材的原始明暗，預設使用參考圖的藍色 `#6A98E8` 與金黃色 `#EEC445`。`controls_config.gd` 集中管理預設顏色、關閉狀態透明度、Hover 亮度、字級與場上張數格式；場景另外提供可調整的顏色屬性，方便背景主題切換時同步換色。

## 放牌、交換、挖牌與棄牌演出

放牌成功後，原卡牌從手牌選取時抬高的位置出發，沿輕微上弧線飛往點選的盤面格子，0.22 秒內快速移動並逐漸減速，尺寸同步過渡至當前牌陣縮放比例。抵達後以 0.035 秒輕壓及 0.065 秒回復完成落定，接著將同一卡牌移交盤面、整理其餘手牌槽位並刷新牌型清單。飛行期間固定鏡頭與目標格位置，落定後依自動追蹤設定恢復適配。

交換成功後，兩張實體牌沿相反側的弧線同時移往對方位置，以 0.3 秒完成起步加速、到位減速及輕微傾斜。挖牌成功後，目標牌立即抖動 0.08 秒，再以拋物線退場：上彈高度為牌高的三分之一，上升速度逐漸降低，頂點垂直速度為零，下落隨重力加速；橫向隨機朝左或右等速移動，整段位移為一個牌寬。卡牌全程保持不透明，持續加速下落，直到旋轉後整張牌越過視窗底部才收起。下落時間依卡牌起點、鏡頭縮放、視窗底部與旋轉後牌面邊界計算；位移使用卡牌所在座標系的尺寸，隨牌陣鏡頭縮放保持比例。

棄牌沿用選取時的卡牌位置，朝畫面左下方加速飛出並輕微旋轉，單張飛行 0.32 秒，多張出發間隔為 0.045 秒。全部選定牌退場後刷新手牌槽位，再由右上牌庫執行既有逐張補牌動畫。其餘手牌沿用原槽位，同一張牌經洗牌再次抽回時，也依序完成退場與補牌。

`src/scripts/playing_card/card_action_animator.gd` 負責卡牌位置、角度、透明度與圖層演出，使用原卡牌實例並在完成後還原視覺狀態，供撤銷或再次抽回使用。`src/configs/playing_card/action_animation_config.gd` 集中管理時間、放牌尺寸過渡與落定回彈、弧線、抖動、拋物線、退場邊距與棄牌淡出參數。挖牌方向使用獨立的演出亂數來源，牌庫沿用核心亂數序列。遊戲控制器在核心操作成功後鎖定輸入，等動作完成再刷新盤面、牌型清單與鏡頭；棄牌的鎖定持續到補牌完成。費用、額度與歷史紀錄由核心成功操作一次提交，撤銷依既有規則還原。

## 逐張發牌

開局、跨關、結算補滿手牌及棄牌補抽皆使用同一個發牌流程。`run_state.gd` 的 `last_draw` 記錄最近一次實際抽牌的卡牌 ID 與逐張抽出後的剩餘數量，支援棄牌堆洗回時的連續抽牌。即使洗回後補抽到同一張卡，也會記錄該次抽牌，供畫面正確呈現。

`src/scripts/hand_area/hand_dealer.gd` 將實際卡牌實例放在牌庫圖示中心，依序由小長大，再快速飛向對應的手牌槽位，落定時恢復原尺寸。每張牌出發時同步更新牌庫數字，牌面與附加圖層沿用同一個實例。發牌期間鎖定遊戲操作，全部落定後恢復。一般撤銷將原牌還回手牌，由撤銷流程更新位置。

`src/configs/hand_area/deal_config.gd` 定義逐張間隔、生長時間、飛行時間與縮放比例。開局六張牌的出發間隔為 0.07 秒，每張生長 0.09 秒、飛行 0.22 秒，前後張的動畫交疊，形成連續俐落的發牌節奏。

目前主畫面以關卡面板、Combo 清單、操作按鈕、場上張數與上限、牌庫與金錢圖示及四顆鏡頭按鈕呈現資訊。數量與限制取自核心狀態，牌庫數字依逐張發牌事件更新，場上張數依盤面刷新。`tests/gameplay/draw_events_test.gd` 驗證金錢生命週期及抽牌事件，`tests/board/board_rules_test.gd` 驗證放牌幾何，`tests/board/camera_math_test.gd` 驗證安全區、待放格適配、縮放錨點與觸控狀態。
