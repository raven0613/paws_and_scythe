# 貓牌發動演出

結算中每次貓牌發動時，來源卡片放大並傾斜，同時從卡片中央拋出本次加成的數字標籤，標籤到位後目標才開始跑數字。外觀參考 `src/assets/ref/cat_card_active.png` 與 `src/assets/ref/gameplay.png` 左下角。計分規則見 [貓牌系統](cat_card.md)，結算整體節奏見 [結算分數演出](settlement.md)。

## 時間軸

卡片放大與數字標籤同時開始，之後兩者各自播放。標籤經過飛行、撞牆反彈與到位的時間後，目標開始跑數字，跑分時間為 `COUNT_DURATION`；逐組效果的目標為本次發動作用的所有 Combo 條，整次效果的目標為中央數字或右側倍率。目標跑完後結算時間軸立即銜接下一個事件；卡片與標籤依自身時鐘停留 `RELEASE_HOLD`，再由卡片補間收回原本大小、角度與透視，標籤同時縮小消失。同一張貓牌在收回期間再次發動時從頭播放。加速時卡片與標籤跟隨播放速度，跳過時立即恢復卡片原狀並隱藏標籤。

標籤顯示加分 `+N` 或倍率 `xN`。王牌貓的最高分獨占與 Copy Cat 的額外計分只播放卡片動作，目標在標籤應到位的同一時間開始跑，節奏與有數字的發動一致。

## 卡片

卡片在 `CARD_POP_DURATION` 內瞬間放大到 `CARD_SCALE`，略為衝過頭再回到定值，同時中心移到相對原本貓牌中心 `CARD_OFFSET` 的位置，逆時針旋轉並以透視傾斜，左上角靠近鏡頭。預設位移依參考圖左上貓牌與放大卡片的中心距離設定，放大後往右上偏移，各位置的貓牌放大後都保持在畫面內；收回時卡片移回原位。影子平常位於卡面右下，放大時同步移到 `CARD_SHADOW_OFFSET` 的左下位置，露出寬度與右下時相同，收回時移回右下。放大同時開始抖動，位移與角度一起抖動，在 `CARD_SHAKE_DURATION` 內衰減。透視傾斜由 shader 對陰影與卡面一起計算，左右與上下傾斜角度和鏡頭距離可分別設定。發動期間卡片位於其他貓牌上層，Hover 與拖曳範圍維持原本的卡片位置。

## 數字標籤

標籤以放大傾斜後的卡片右上角為原點，跟隨卡片的放大、旋轉與收回，卡片抖動只作用於卡片本身。標籤從卡片中央沿拋物線噴向右上角的牆面，途中由無長到原尺寸並轉到到位角度；撞牆後等速彈向左下一小段，再彈向左上減速到位，反彈與到位都在卡片右上角的小區塊內完成。到位時標籤放大到超過原尺寸再縮回，同時來回旋轉並抖動，最後停在原位。

標籤由三個方塊組成，三個方塊各有不同的旋轉角度：主體依 `BADGE_ROTATION` 傾斜，兩節尾巴再依 `TAIL_ROTATIONS` 各自多轉一個角度，預設依參考圖分別約為 30°、48° 與 -12°，三者從出現起就維持各自的角度差一起轉動。最大的主體方塊固定大小並承載白色描邊文字，文字可超出方塊，到位後保持正向，只跟隨主體的旋轉抖動。後方兩節尾巴方塊逐節變小、變淺，整條尾巴全程以主體左下方的斜線為中心擺動。飛行、撞牆與反彈時，主體的橫向移動把第一節推向移動的反側，推彎角度有上限，尾巴始終留在主體左下側；到位時主體的來回旋轉帶動第一節加大幅度擺動，第二節跟隨第一節並落後一拍，整條尾巴呈波浪狀左右擺動，Q 彈地衰減後停在左下斜線上。兩節的方向與間距各自以彈簧追隨。主體遠離尾巴時方塊間距拉長，朝尾巴移動時間距擠短，最短保留固定間距。尾巴軌跡在發動時以固定步長預先計算，加速播放與一般播放呈現相同動態。

## 設定

`src/configs/cat_cards/cat_activation_config.gd` 集中所有發動演出參數：

| 分類 | 內容 |
| ---- | ---- |
| 時間軸 | 發動圖層、目標跑分時間、目標跑完後的停留時間。 |
| 卡片姿態 | 放大後相對原本貓牌中心的位移、發動時影子相對卡面的位置、放大倍率、旋轉、透視傾斜、鏡頭距離、透視繪製邊距、放大時間與衝過頭幅度、收回時間與曲線。 |
| 卡片抖動 | 抖動時間、位移與角度幅度、各軸頻率。 |
| 標籤路徑 | 撞牆點、左下反彈點、到位點、拋物線高度，以及飛行、反彈、到位各段時間。 |
| 標籤姿態 | 飛行起始角度與到位角度，到位放大的時間、峰值位置、倍率、旋轉幅度與次數、抖動幅度與頻率，收回時間與脹大幅度。 |
| 標籤外觀 | 主體邊長與顏色，文字字級、顏色、描邊顏色與粗細。 |
| 尾巴 | 各節大小、顏色與相對主體的旋轉角度、靜止斜線方向與間距、最短間距、遠離時的拉長比例、橫向推彎比例與上限、到位擺動倍率、方向與間距的彈簧硬度及阻尼、模擬步長與到位後的模擬長度。 |

## 元件

| 檔案 | 責任 |
| ---- | ---- |
| `src/service/cat_cards/activation/activation_timing.gd` | 標籤到位、開始收回、完成的時間點與共用補間曲線。 |
| `src/service/cat_cards/activation/card_motion.gd` | 卡片位移、影子位置、放大、旋轉、透視、抖動、收回姿態，以及標籤原點的卡片右上角。 |
| `src/service/cat_cards/activation/badge_motion.gd` | 標籤路徑、縮放、旋轉、到位擺動與抖動。 |
| `src/service/cat_cards/activation/badge_tail.gd` | 尾巴方塊的彈簧模擬與取樣。 |
| `src/scripts/cat_cards/activation/card_tilt.gdshader` | 卡片陰影與卡面的透視傾斜。 |
| `src/scripts/cat_cards/activation/activation_badge.gd` | 依計算結果繪製尾巴、主體與文字。 |
| `src/scripts/cat_cards/cat_card_view.gd` | 以自身時鐘驅動卡片 `visual` 節點與標籤。 |
| `src/scripts/gameplay/settlement_presenter.gd` | 發動卡片後等待標籤到位，再驅動目標跑數字。 |

核心測試位於 `tests/cat_cards/activation_test.gd`，驗證時間點、卡片位移放大傾斜與抖動衰減、標籤原點跟隨移動後的右上角、收回補間與回到原位、影子隨放大移到左下並隨收回移回、標籤由卡片中央長出、拋物線飛行、撞牆與反彈方向、到位點、到位放大與旋轉、文字正向、收回縮小，以及尾巴在主體遠離時拉長、反彈靠近時擠短、全程留在主體左下側、到位時往斜線兩側擺動、第二節落後第一節形成波浪，並停在左下靜止位置。
