# 高分衝擊波、熱浪與火焰發光

全像彩虹與銀河兩種高分表演都有火焰發光、火焰熱浪與撞頂衝擊波，兩者各自一組數值，銀河的扭曲更強、範圍更大、光暈更亮。表演等級、火焰與撞擊表演的共用規則見 [結算分數演出](settlement.md)，銀河的撞頂轉場見 [銀河轉場](galaxy_transition.md)。

## 火焰發光

火焰像霓虹燈管般由本身發光：每個方塊維持該層火焰的色相與飽和度提高亮度，外暈與該處火焰同色，從整團火焰的邊緣開始，以邊緣最亮的強度往外柔和淡出。發光的方塊在 CanvasGroup 內以原尺寸與提亮色合成整團火焰的輪廓，紅色主體發紅光、黃色頂冠發黃光，邊緣的小方點一起發光；外暈以正常混色畫在火焰後方，淡出距離以基準畫面像素設定並依畫面縮放換算，任何視窗大小的光暈寬度一致。提亮比例、淡出距離與邊緣不透明度各自設定。發光從跑分時火焰燃起就開始，跟著方塊的上升、縮小與漸強一起變化；銀河等級的發光跟著火焰漸變，在換成銀河後由彩虹組的數值過渡到銀河組。

## 熱浪

熱浪範圍是火焰外圍邊緣漸淡的橢圓，背景以向上飄動的雙層雜訊位移，像隔著熱氣看過去般扭曲，扭曲由橢圓中心往邊緣漸淡；橢圓依字形範圍定位並跟隨數字的位置與縮放，數字落地彈跳時一起移動。跑分時兩種等級共用一組輕微的熱浪設定，強度隨火焰漸強成長，火焰燃起時熱浪一起出現。衝擊波發出後，熱浪在衝擊波擴散期間增強到該等級的誇張設定，範圍、強度、密度與飄動速度一起過渡，之後維持到結算結束。雜訊的飄移量逐格累加，飄動速度改變時連續加快。

## 衝擊波

數字炸開的瞬間，從數字當下的中心發出一圈扭曲環，以減速擴散到最終半徑，環的前後兩側推擠背景，環上紅藍色微微錯開，即使平坦的背景也看得出環掃過；位移與色散在擴散期間逐漸衰減到 0。每次結算只發出一次：全像彩虹在撞頂時發出，銀河在反轉幀結束、換成銀河並噴出碎片的同一刻發出。

## 圖層

衝擊波與熱浪共用一層鋪滿畫面的扭曲，讀取一次下層畫面後位移取樣，高分結算期間有強度時顯示。扭曲層位於盤面背景、周邊 UI、Combo 條標題與關卡分數之上，位於銀河暗角、飛行粒子、中央分數與火焰、右側倍率之下，因此背景與周邊 UI 被扭曲，分數與火焰保持清晰。加速播放時衝擊波與熱浪跟隨播放速度，結算結束及跳過時隱藏扭曲層。

## 設定

| 設定 | 內容 |
| ---- | ---- |
| `celebration_config.gd` 的 `FIRE_GLOW_HOLOGRAPHIC`、`FIRE_GLOW_GALAXY` | 火焰方塊的提亮比例 `brighten`、外暈由火焰邊緣淡出到消失的距離 `blur`（基準畫面像素）與外暈在火焰邊緣的不透明度 `halo_alpha`。 |
| `celebration_config.gd` 的開關 | `FIRE_GLOW_ENABLED`、`SHOCKWAVE_ENABLED`、`HEAT_HAZE_ENABLED` 各自開關三種效果。 |
| `impact_distortion_config.gd` 的 `SHOCKWAVE` | 依等級設定擴散時間、最終半徑與環寬（以畫面半高為 1）、最大位移與色散錯開的像素。 |
| `impact_distortion_config.gd` 的 `HEAT_HAZE_COUNT`、`HEAT_HAZE` | 跑分時的共用熱浪與各等級衝擊波後的熱浪：橢圓半徑（相對數字半寬與字高）、中心離字底的高度、最大位移像素、雜訊密度與向上飄動速度。 |
| `score_feedback_config.gd` 的 `DISTORTION_LAYER` | 扭曲層在結算圖層中的位置。 |

## 元件

| 檔案 | 責任 |
| ---- | ---- |
| `src/service/score/impact_distortion.gd` | 衝擊波的半徑、環寬、強度與色散，熱浪由跑分設定到衝擊波後設定的過渡與橢圓範圍。 |
| `src/service/score/flame_math.gd` | 火焰發光的兩組混合與火焰方塊的提亮顏色。 |
| `src/scripts/score/celebration/impact_distortion.gd`、`impact_distortion.gdshader` | 鋪滿畫面的扭曲層，換算畫布像素並繪製衝擊波、色散與熱浪。 |
| `src/scripts/score/celebration/block_flame.gd`、`flame_glow.gdshader` | 以提亮色繪製火焰方塊，並在 CanvasGroup 內以相同的方塊合成同色的外暈輪廓，由邊緣往外淡出後畫在火焰後方；淡出距離依畫面縮放換算成螢幕像素。 |
| `src/scripts/score/score_counter.gd` | 在炸開的瞬間發出衝擊波，逐格更新衝擊波、熱浪飄移量與跟隨數字的熱浪範圍。 |

核心測試位於 `tests/score/impact_distortion_test.gd`，驗證兩種等級的衝擊波在發出前保持平靜、由數字中心以完整強度與色散發出、邊擴散邊衰減且減速擴散、擴散一半時保留一半強度、結束時到達最終半徑並歸零；熱浪在火焰燃起前為 0、跑分時隨火焰成長、衝擊波發出時由跑分強度起步、擴散期間增強並在結束時維持誇張設定、範圍包住字形上方的火焰；銀河的衝擊波、色散與熱浪比全像彩虹強；以及扭曲層位於周邊標籤之上、暗角、粒子與數字之下。`tests/score/flame_math_test.gd` 驗證發光跟隨兩組漸變、外暈邊緣的不透明度在完整範圍內、提亮的方塊維持火焰色相與飽和度並依比例提高亮度，以及銀河的提亮、外暈淡出距離與亮度皆比全像彩虹強。
